# The Art of Flowing

A serene, circadian-themed personal dashboard using React + TypeScript. Features include:

- Dynamic day/night (circadian) theming
- Glassmorphic, whitespace-rich UI
- Playfair Display and Inter font pairing
- Sidebar navigation
- Home (snapshot), Finance, Manifesto pages scaffolded
- Local storage for data persistence
- Ready to expand for Projects, Reflection, Wisdom

## Getting Started

1. `npm install`
2. `npm run dev` (or `npm start` if using CRA)

## Expand

- Add additional pages/components for Projects, Reflection, Wisdom.
- Refine style, add SVG backgrounds, glassmorphic effects, subtle animation.
- Configure PWA in `manifest.json`.

## Design Philosophy

Calm, open, gently guiding. See `/src/pages/Home.tsx` and `/src/pages/Finance.tsx` for core style and structure.
